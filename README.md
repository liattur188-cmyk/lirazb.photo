# לירז בוחניק — אתר צילום עם ממשק ניהול

אתר תדמית רספונסיבי בעברית, עם Pages CMS ו־Cloudflare Pages. אין צורך בשרת, בסיס נתונים או שירות אחסון בתשלום לתחילת הדרך.

## פתיחת תצוגה מקדימה מקומית
דרוש Node.js (גרסה 18 ומעלה). בתיקיית הפרויקט:

```bash
node scripts/build.js
npx serve dist
```

פתחו בדפדפן את הכתובת שמציג `serve`. אין לפתוח index.html ישירות כ־file:// כי האתר קורא קובץ JSON.

## פרסום האתר
1. הירשמי ל־GitHub (github.com), צרי מאגר חדש (Repository) והעלי אליו **את תוכן התיקייה הזו** (כולל `.pages.yml`, הקובץ המוסתר), ללא תיקיית `dist`.
2. פתחי dash.cloudflare.com → Workers & Pages → Create → Pages → Connect to Git.
3. בחרי את המאגר והגדירי: **Build command** = `node scripts/build.js`; **Build output directory** = `dist`.
4. פרסמי. Cloudflare יספק כתובת זמנית בסיומת `pages.dev`. לאחר מכן ניתן לחבר דומיין אישי בהגדרות הפרויקט.
5. היכנסי אל https://app.pagescms.org והתחברי באמצעות GitHub. התקיני את Pages CMS GitHub App ובחרי במאגר האתר. התצורה כבר כלולה בקובץ `.pages.yml`.
6. במסך הניהול יופיעו **הגדרות האתר והתוכן** ו־**גלריות צילום**. העלאת תמונות מתבצעת דרך מנהל המדיה/שדות התמונות. לחצי Save; השינוי נשמר ב־GitHub ו־Cloudflare יפרסם גרסה חדשה אוטומטית.

## ניהול תמונות וגלריות
- להחלפת תמונת הכניסה: הגדרות האתר והתוכן → תמונה ראשית.
- להחלפת תמונת אודות: הגדרות האתר והתוכן → תמונה לאודות.
- לגלריה חדשה: גלריות צילום → New → שם, תיאור, תמונת שער ותמונות הגלריה, Published → Save.
- להסרת גלריה מהאתר, בטלי את השדה 'להציג באתר'.
- הסדר נקבע לפי השדה 'סדר תצוגה'.
- יש להעלות תמונות JPG / WebP דחוסות לתצוגת אינטרנט (מומלץ לרוב 1600–2200 פיקסלים בצלע הארוכה ובגודל של עד 1–2 MB לתמונה). **לא להעלות קובצי צילום מקוריים כבדים**: הם יתפסו נפח במאגר ויאטו את האתר.

## יצירת קשר
הטופס באתר **אינו שומר פרטי פונים על שרת**. אם מוגדר מספר וואטסאפ, לחיצה על שליחה פותחת הודעה מוכנה בוואטסאפ; אם אין וואטסאפ אבל יש אימייל, הוא יפתח טיוטת מייל. המבקר/ת צריכים ללחוץ Send ביישום החיצוני. אם אין פרטי קשר מוגדרים, האתר יציג הודעת הגדרה. מספר הוואטסאפ צריך לכלול קידומת מדינה ללא פלוס, לדוגמה: `972501234567` (דוגמה בלבד).

## פרטים להשלמה לפני פרסום ציבורי
- תמונות אמיתיות במקום מצייני המקום; 3 הגלריות הראשונות הן **דוגמאות בלבד** ויש להתאים את שמותיהן לשירותים האמיתיים.
- טקסט אודות, אזור פעילות, מספר טלפון, כתובת דוא״ל וקישור אינסטגרם.
- מדיניות פרטיות מותאמת לפעילות האתר ולעיבוד המידע בפועל; בדיקת חובות נגישות והתאמות נוספות בהתאם לדין החל.
- בדיקת טופס הקשר במכשיר נייד ובדפדפן.
- דומיין עסקי אם רוצים, אחרי בחירת שם ובדיקת זמינות.

## מבנה הפרויקט
- `content/site.json`: התוכן והפרטים הכלליים.
- `content/galleries/*.json`: גלריות (קובץ לכל גלריה).
- `media/`: תמונות שהועלו דרך Pages CMS.
- `.pages.yml`: ממשק הניהול.
- `scripts/build.js`: יוצר `dist/` ומייצר קובץ נתונים לכל הגלריות.
- `assets/logo.png`: הלוגו שנשלח (כלול בחבילה לשימוש עתידי; הכותרת הנוכחית באתר היא טיפוגרפית כדי לשמור על מראה נקי).

הערה: שינויים ב־Pages CMS מחייבים שהאתר כבר נמצא במאגר GitHub שהמשתמשת שולטת בו. החבילה אינה אתר שכבר פורסם ואינה ממשק ניהול פעיל לפני חיבור החשבונות.
